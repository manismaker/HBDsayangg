OUR LITTLE UNIVERSE — React version

Cara menjalankan:
1. Ekstrak ZIP ini.
2. Buka index.html di browser.
3. Internet diperlukan saat membuka pertama kali karena React 18 dan Babel dimuat dari CDN serta font dari Google Fonts.
4. PIN demo: 123456.

- Foto dan musik berada di folder assets.
- Tidak membutuhkan npm/Vite untuk sekadar membuka website.
